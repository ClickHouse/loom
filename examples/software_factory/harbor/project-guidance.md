# Repository context

Use Loom to discover and read unchanged source in the indexed roots and to
retrieve linked project history when needed. Use the source already in context
when it answers your question. Check source references and link freshness before
relying on a historical note.

Use local tools for edits, tests, Git, and source outside Loom's coverage.
Read locally when Loom is unavailable or reports that it cannot supply the
needed source. State the missing evidence when you fall back for indexed source.
Use the working copy when you need to read a file you changed.

Choose the calls, edits and verification needed to solve the issue.
