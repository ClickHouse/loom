# Features

Loom gives agents memory, source material, and records of prior work in a namespace they can access.

## Find and share context

- [Write and revise memory](memory/writing.md)
  Save facts, import records, and review conflicts.
- [Retrieve context](unified-search.md)
  Search across memory, profile data, documents, and past conversations.
- [Search and cite documents](knowledge.md)
  Ingest files and document sources, then retrieve cited passages.
- [Index repositories](code-index/overview.md)
  Find definitions, callers, and code revisions. Link memory to the source it describes.

## Track work across sessions

- [Conversations and sessions](conversations-and-sessions.md) cover transcript capture and session briefs.
- [Runs](runs.md) record task execution and the memories it used.
- [Tasks and decisions](tasks-and-decisions.md) give agents a shared inbox and a decision record.
- [Tracker](tracker/overview.md) connects issues, pull requests, and CI history.
- [Entity graph](entity-graph.md) relates entities from namespace data.

## Govern use

- [Namespaces and sharing](namespaces-and-sharing.md) explains what readers and writers can access.
- [History and provenance](memory/history-and-provenance.md) shows who wrote a memory and how it changed.
- [Retention and erasure](memory/retention-and-erasure.md) covers expiry and scoped deletion.
- [Audit](observability/audit.md), [cost and usage](observability/cost-and-usage.md), and [telemetry](observability/telemetry.md) show what the server did and what model calls cost.

Connect via an [integration](integrations/index.md) or review activity and records in the [dashboard](dashboard.md).
