# Documentation

- Describe the system as it is now: no "new", "previously", dates, people, hosts, internal namespaces, ticket or decision numbers (`test_public_copy.py`). History goes in the PR body.
- Generated pages and regions under `docs/reference/` come from their generators (`settings_reference.py`, `docs_reference.py`); never hand-edit them.
- Relative links and `#anchors` must resolve (`test_doc_links.py`).
- Follow the [documentation style guide](../../docs/development/documentation-style.md).
- `i18n/<lang>/` holds machine translations of the README, the quickstart and the use-case pages, generated by `scripts/i18n/translate.py` after an English edit lands on main (`.github/workflows/i18n.yml`); never edit them by hand, and edit the English page instead. A new page in that set goes into `SOURCES`, and the PR that adds it commits its six translations, made with `python -m scripts.i18n.translate update` and an `ANTHROPIC_API_KEY` (`test_i18n.py` requires every page); after a change to the prompt, a banner or the model, run the workflow with `all`.
