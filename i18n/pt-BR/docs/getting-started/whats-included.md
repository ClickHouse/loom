# O que está incluído

Esta página lista as principais capacidades do Loom, em auto-hospedagem a partir do repositório Apache-2.0: uma seção por área, com cada linha apontando para a página que a descreve. O [índice da documentação](https://github.com/ClickHouse/loom/blob/main/docs/index.md) mapeia o restante da documentação. Algumas capacidades precisam ser ativadas; a página vinculada explica como, e as chaves booleanas que carregam como false estão listadas em [estado](https://github.com/ClickHouse/loom/blob/main/docs/reference/status.md). O embedder é escolha sua: o modelo local incluído, um provedor hospedado ou um endpoint compatível com OpenAI que você mesmo executa. Extração, resumos e respostas com citações exigem um LLM de verdade ([modelos e chaves de API](https://github.com/ClickHouse/loom/blob/main/docs/getting-started/models-and-keys.md)).
