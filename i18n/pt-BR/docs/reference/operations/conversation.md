# Operações de `conversation`

Os campos exatos que cada operação `conversation.*` recebe e retorna.

<!-- Generated by `python scripts/codegen/docs_reference.py` from the op registry; edit the models, not this page. -->

Toda op é `POST /v1/<op>` via HTTP e a ferramenta MCP `loom_<op>`. Os campos de identidade (`org`, `namespace`, `agent`, `user_id`, `session_id`) são preenchidos a partir do token e da sessão MCP quando o transporte consegue fazer isso. Em uma chamada HTTP sem token em um servidor de usuário único, é usada a org da instalação em todas as ops, exceto `code.*` e `tracker.*` (que mantêm a org do próprio plano), e em [algumas ops](https://github.com/ClickHouse/loom/blob/main/docs/reference/http-api.md#request) também o namespace e o agente. Veja [identidades e namespaces](../../concepts/identities-and-namespaces.md). O [índice de operações](https://github.com/ClickHouse/loom/blob/main/docs/reference/operations.md) explica role, kind e a listagem `all` do MCP. Campos de entrada desconhecidos são atendidos e listados em `ignored_args`.

## `conversation.compact`

Resume turnos antigos em um único turno de sistema com embedding e marca os originais com tombstone.

`POST /v1/conversation.compact` · MCP `loom_conversation_compact` · role `writer` · idempotente · auditado · não listado no toolset `all` do MCP

| Campo de entrada | Tipo | Padrão | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obrigatório | O tenant (primeiro elemento da tupla de identidade). |
| `namespace` | `str` | obrigatório | O namespace que a op lê ou grava. |
| `agent` | `str` | obrigatório | O agente que grava ou lê; `'-'` ou `'*'` significa qualquer agente, onde a op permitir. |
| `thread_id` | `str` | obrigatório | A thread a compactar. |
| `keep_recent` | `int` | `10` | Esta quantidade das mensagens mais recentes permanece literal; as mais antigas são resumidas, quantas couberem no prompt do sumarizador. |
| `min_to_compact` | `int` | `4` | Ignora quando há menos turnos novos que este valor antes das últimas keep_recent; um resumo anterior não conta. |

| Campo de saída | Tipo | Significado |
| --- | --- | --- |
| `compacted` | `bool` | Verdadeiro quando um resumo foi gravado e os originais receberam tombstone; `reason` explica o motivo caso contrário. |
| `messages_summarized` | `int` | Quantas mensagens mais antigas o resumo substituiu, sem contar um resumo anterior; 0 quando não houve compactação. |
| `summary_msg_id` | `str` | Id da mensagem sintética de resumo `system`; vazio quando não houve compactação. |
| `tokens_in` | `int` | Tokens de prompt que a chamada de LLM do sumarizador usou; 0 quando nenhuma chamada foi feita. |
| `tokens_out` | `int` | Tokens de conclusão do resumo; 0 quando nenhuma chamada foi feita. |
| `reason` | `str` | Por que compacted=False: nothing-to-compact, below-min-to-compact, already-compacted, summarizer-empty, embed-failed (tente de novo quando o embedder responder), summary-high-sensitivity (não tente de novo: a mesma janela gera o mesmo resumo). |

## `conversation.update`

Atualiza o título, os metadados ou o run_id de uma thread.

`POST /v1/conversation.update` · MCP `loom_conversation_update` · papel `writer` · idempotente · não listado no toolset `all` do MCP

| Campo de entrada | Tipo | Padrão | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obrigatório | O tenant (primeiro elemento da tupla de identidade). |
| `namespace` | `str` | obrigatório | O namespace que a op lê ou grava. |
| `agent` | `str` | obrigatório | O agente que grava ou lê; `'-'` ou `'*'` significa qualquer agente, onde a op permite. |
