# Operações de `consolidations`

Os campos exatos que cada operação `consolidations.*` recebe e retorna.

<!-- Generated by `python scripts/codegen/docs_reference.py` from the op registry; edit the models, not this page. -->

Toda op é `POST /v1/<op>` via HTTP e a ferramenta MCP `loom_<op>`. Os campos de identidade (`org`, `namespace`, `agent`, `user_id`, `session_id`) são preenchidos a partir do token e da sessão MCP quando o transporte consegue fazer isso; em uma chamada HTTP sem token em um servidor de usuário único, é preenchida a org da instalação em todas as ops, exceto `code.*` e `tracker.*` (que mantêm a org do próprio plano), e em [algumas ops](https://github.com/ClickHouse/loom/blob/main/docs/reference/http-api.md#request) também o namespace e o agente; veja [identidades e namespaces](../../concepts/identities-and-namespaces.md). O [índice de operações](https://github.com/ClickHouse/loom/blob/main/docs/reference/operations.md) explica role, kind e a listagem `all` do MCP. Campos de entrada desconhecidos são aceitos e listados em `ignored_args`.

## `consolidations.list`

Histórico de execuções de consolidação no escopo do namespace. agent e user_id são opcionais: quando omitidos, as execuções são agregadas entre eles.

`POST /v1/consolidations.list` · MCP `loom_consolidations_list` · role `viewer` · leitura · não listada no toolset `all` do MCP

| Campo de entrada | Tipo | Padrão | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obrigatório | O tenant (primeiro elemento da tupla de identidade). |
| `namespace` | `str` | obrigatório | O namespace que a op lê ou grava. |
| `agent` | `str` | `'-'` | O agente que grava ou lê; `'-'` ou `'*'` significa qualquer agente, onde a op permitir. |
| `user_id` | `str` | `'-'` | O usuário final a que a linha pertence; `'-'` para nenhum. |
| `session_id` | `str` | `'-'` | A sessão ou conversa a que a linha pertence; `'-'` para nenhuma. |
| `run_id` | `str` | `'-'` | A execução do agente (escopo da tarefa) a que a chamada pertence; `'-'` para nenhuma. |
| `limit` | `int` | `50` | No máximo este número de execuções retornadas, das mais recentes para as mais antigas. |

| Campo de saída | Tipo | Significado |
| --- | --- | --- |
| `rows` | `list[ConsolidationRunRow]` | As execuções de consolidação do namespace, das mais recentes para as mais antigas, uma por cluster examinado. |
