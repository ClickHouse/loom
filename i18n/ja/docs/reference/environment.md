# 環境変数リファレンス

Loom の設定のほとんどは settings フィールドです。これは `server.settings.Settings` のフィールドに対応する環境変数 `LOOM_<FIELD>` で、デフォルト値と意味は自動生成された[設定リファレンス](https://github.com/ClickHouse/loom/blob/main/docs/reference/configuration.md)に一覧があります。このページでは、それ以外の変数を扱います。具体的には、サーバー、CLI、SDK、プラグイン、コンテナイメージ、compose ファイル、運用スクリプトが `os.environ`（またはシェルの `${VAR}`）で直接読み取る変数です。このうち `LOOM_*` の変数は `NON_SETTINGS_ENV`（`server/settings/_env.py`）に、webhook の署名シークレットのようなファミリーの場合は `NON_SETTINGS_ENV_PREFIXES` に一覧があり、サーバーの未知の変数に対する警告はこれらを対象外とします。`tests/unit/test_environment_reference.py` は、これらの一覧とこのページを一致させています。

## コンテナイメージと uvicorn

イメージのコマンドである `scripts/serve.sh` がこれらを読み取り、uvicorn を起動します。`scripts/serve.sh` は環境変数のみから値を取得し、`.env` や `LOOM_ENV_FILE` からは取得しません（compose の `env_file:` は値を環境変数に設定します）。ただし設定フィールドの `LOOM_WEB_WORKERS`、`LOOM_TRUSTED_PROXIES`、`LOOM_RUNTIME_DIR` は例外で、サーバーが読み込む際に、環境変数、env ファイル、[設定ファイル](https://github.com/ClickHouse/loom/blob/main/docs/reference/configuration.md)の順に解決されます。uvicorn 自身の `UVICORN_<OPTION>` 変数は読み取られません。`scripts/serve.sh` が渡さない uvicorn のオプションに対してこの変数が設定されている場合、Web ティアは起動を拒否します。

| 変数                       | デフォルト           | 意味                                                                                                                                                                                                                                                                                                                                                   |
| -------------------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PORT`                     | `7777`               | uvicorn がコンテナ内でバインドするポート。                                                                                                                                                                                                                                                                                                             |
| `LOOM_LISTEN_HOST`         | `127.0.0.1`          | `uvicorn --host`：待ち受けるアドレス。イメージでは `0.0.0.0` に設定されます。`LOOM_BIND_HOST` は起動時チェックが読み取るアドレスのままで、環境変数に設定がない場合、スクリプトはこれを非ループバックの待ち受けアドレスに設定します（env ファイルや設定ファイルの値は上書きされます）。                                                                 |
| `LOOM_WEB_WORKERS`         | CPU ごとに 1、最大 8 | `uvicorn --workers`。未設定の場合、コンテナが使用できる CPU（cpuset を CPU クォータで下げた値）ごとに 1 つ、メモリ 1 GiB あたり最大 1 つ、かつ最大 8 です。`.env` でワーカー数を指定していない限り、compose ファイルが設定します。`deploy/standalone` と開発スタックでは 2、クラウドスタックとカラースタックでは 1 です。設定フィールドでもあり、レートリミッターはこの値で予算を割ります。 |
| `LOOM_UVICORN_LOOP`        | `asyncio`            | `uvicorn --loop`：`asyncio`、`auto`、`uvloop` のいずれか。uvloop は git を起動するたびにプロセス全体をフォークするため、ループが停止します。                                                                                                                                                                                                            |
| `LOOM_TRUSTED_PROXIES`     | `127.0.0.1`          | `uvicorn --forwarded-allow-ips`：`X-Forwarded-For`／`-Proto` を適用するピア。                                                                                                                                                                                                                                                                          |
| `LOOM_GRACEFUL_SHUTDOWN_S` | `10`                 | `uvicorn --timeout-graceful-shutdown`：停止中のプロセスがリクエストを処理しきるまで待つ時間。                                                                                                                                                                                                                                                          |
| `LOOM_KEEP_ALIVE_S`        | `5`                  | `uvicorn --timeout-keep-alive`：アイドル状態の接続を開いたままにする時間。接続を再利用するロードバランサーの背後では、そのアイドルタイムアウトより長くしてください。                                                                                                                                                                                    |

ビルド引数：`LOOM_BUILD_COMMIT`（イメージに `LOOM_BUILD_COMMIT` として埋め込まれ、`build_commit` として報告されます）。イメージには常にローカル CPU エンベッダーとそのデフォルトモデルが含まれ、`LOOM_LOCAL_EMBEDDING_MODEL_DIR=/app/models` が設定されます。残りの `ARG` は、コンパイラティアのインデクサー用のツールチェーンのバージョンとチェックサムを固定します（`GO_VERSION`、`NODE_VERSION`、`SCIP_GO_VERSION`、`SCIP_CLANG_VERSION`、それらの `*_SHA256*` の値、および LLVM の署名鍵のフィンガープリントである `LLVM_SIGNER_FPR`）。`scripts/install-code-toolchains.sh` は、npm でインストールするツール（scip-typescript、scip-python、パッケージマネージャー）のバージョンを固定します。

compose ファイル内のその他の `${LOOM_*}` 参照は、compose レベルのデフォルトが与えられた設定フィールドと、上記の uvicorn 変数です。インストーラーは、2 つのイメージリポジトリ（`LOOM_IMAGE_REPOSITORY`、`LOOM_EXTRACTOR_IMAGE_REPOSITORY`）、タグ、ポート、バインドホスト、`LOOM_CLICKHOUSE_IMAGE` が指定された場合に `.env` に保持します。標準の `.env` が設定する内容は[クイックスタート](../getting-started/quickstart.md)を参照してください。

## コーディングエージェントのプラグインとフックスクリプト

| 変数                                       | 読み取り元                                                                                              | デフォルト                                                                                    | 意味                                                                                              |

| `LOOM_ORG`, `LOOM_NAMESPACE`, `LOOM_AGENT` | プラグインの `lib/loom-client.mjs`、`integrations/cursor/`、`integrations/generic/`、`dev/loom_init.py` | `~/.loom/config.json`、次にトークンのクレーム、次に `default` / `coding` / クライアント名 | フックとスクリプトがキャプチャした行を書き込む際に使用する ID。 |

| `LOOM_HOOK_EXIT_MS`                        | プラグインの `lib/loom-client.mjs`                                                                      | `LOOM_HOOK_TIMEOUT_MS`                                                                        | フックプロセスが送信後、終了するまで待機する時間。 |
| `LOOM_SHUNT_READ_CAP`                      | プラグインの `hooks/loom-code-shunt.mjs`                                                                | `0`（無効）                                                                                   | インデックス済みで未変更のファイルの範囲指定読み取りが、この行数を超えると、代わりにコードツールへ振り分けられます。 |

[Claude Code プラグイン](https://github.com/ClickHouse/loom/blob/main/docs/features/integrations/claude-code.md)を参照してください。
