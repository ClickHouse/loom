# ベンチマークのカバレッジ

このマトリクスは、Loom のメモリ、ナレッジ、コードの各フローのうち、どの部分に再現可能な公開測定があるかを示します。測定済みの動作、実行可能なハーネス、そして公開された品質の根拠がまだない製品機能を区別しています。

<a id="status"></a>

## ステータス

| ステータス | 意味 |
| ------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **公開済み**              | コミット済みの結果アーティファクト、モデルレコード、プロトコル、制限事項、再現コマンドが存在する。                |
| **一部公開**              | 公開されている結果は評価対象の問いの一部を測定しているが、フロー全体や代表的な規模は測定していない。  |
| **ハーネスのみ**          | 実行可能なプロトコルは存在するが、公開する性能の主張を裏付ける、コミット済みの実プロバイダーでの測定結果はない。     |
| **公開された測定なし** | この問いに対する完全な公開プロトコルとアーティファクトがリポジトリにない。製品ドキュメントは存在する場合がある。 |

ユニットテスト、ドライラン、フェイクプロバイダーのゲートは、公開された品質結果とは見なされません。公開された数値の出典は[結果台帳](https://github.com/ClickHouse/loom/blob/main/docs/benchmarks/results.md)であり、実行可能なプロトコルの出典は[ハーネス一覧](https://github.com/ClickHouse/loom/blob/main/bench/README.md)です。

<a id="what-belongs-in-the-readme"></a>

## README に掲載する内容

README には、評価対象の結果の種類ごとにまとめた複数の公開ベンチマークを掲載します。行を README に載せられるのは、このマトリクスで **公開済み** となっており、サンプル数が結果を解釈できるほど十分にあり、その結果がどこまで一般化できないかを一文で明確に述べられる場合に限ります。

**ハーネスのみ** や **公開測定なし** の行は、README の性能に関する主張に移さないでください。代わりにこのマトリクスへリンクしてください。ハーネスが示すのは、Loom を測定できるということだけであり、Loom の性能が高いことを示すものではありません。

## 公開予定の項目

以下の各項目は、上記のマトリクスにある評価上の問いに答えるものです。

- **書き込みの整合性と訂正：** 公開されている1つの会話コーパスにおける、抽出の精度、誤ったメモリの発生率、置き換え（supersession）の発生率、古い回答の発生率。
- **ナレッジ RAG：** テキストドキュメントにおける検索、回答、引用の品質。続いて、PDF、CSV、構造化テキストを対象に、ライセンスが明確な形式忠実度コーパスを用いた評価を行います。
- **コードエージェントのエンドツーエンドの成果：** リークを抑制したパッチ生成とテスト成功率。Loom を使わない同じエージェントとの対比で測定します。
- **実環境でのコードの移植性：** 既存の多言語、SQL/シェル、OSS のフィクスチャを対象にした、実プロバイダでの測定。
- **インデックスのコストと鮮度：** リポジトリのサイズ別のコールドおよびインクリメンタルの曲線。ハードウェア、ClickHouse のストレージ、ワーカーのリソースも記録します。
- **容量と信頼性：** 複数のテナントにまたがるメモリとコードの混在ワークロード。続いて、ワーカー、ClickHouse、ネットワークの障害注入を行います。
- **安全性とプライバシー：** 名前付きの攻撃に対する結果は個別に公開します。汎用的な安全性スコアにまとめることはしません。

新しい結果はいずれも、[結果の追加](https://github.com/ClickHouse/loom/blob/main/docs/benchmarks/results.md#adding-a-result)に従います。raw アーティファクトをコミットし、使用したすべてのモデルとサーバーのビルドを記録し、データセットのライセンスを明記し、実行したコマンドをそのまま含め、失敗や否定的な結果も報告し、不確かさ、または1問の変動が結果に与える大きさを添えます。
