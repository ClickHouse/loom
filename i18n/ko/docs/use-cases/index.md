# 사용 사례

각 페이지는 사람과 에이전트가 도구를 찾을 때 던지는 질문 하나에 답합니다. 해당 요구에 Loom이 무엇을 해 주는지, 어디서 시작하면 되는지를 설명합니다.

| 요구 사항                                                         | 페이지                                                 |
| ----------------------------------------------------------------- | ------------------------------------------------------ |
| AI 에이전트를 위한 장기 메모리와 공유 메모리 (MCP 메모리 서버)    | [Agent memory](agent-memory.md)                        |
| 에이전트를 위한 지식 및 문서 검색 (RAG)                           | [Document search](document-search.md)                  |
| 코딩 에이전트를 위한 코드 인덱스와 코드 인텔리전스                | [Code index](code-intelligence.md)                     |
| 코딩 에이전트의 모델 비용 절감                                    | [Coding-agent cost](coding-agent-cost.md)              |
| 멀티 에이전트 워크플로에서 에이전트 간 컨텍스트 공유              | [Multi-agent](multi-agent.md)                          |
| 자율 에이전트를 위한 메모리, 회상, 감사, 삭제                     | [Autonomous agents](autonomous-agents.md)              |
| 에이전트 실행, 트레이스, 트래커, PR 이력                          | [Runs and PR history](runs-and-pr-history.md)          |
| Docker 또는 Kubernetes 기반의 ClickHouse 셀프 호스팅 에이전트 메모리 | [Self-hosted on ClickHouse](self-hosted-clickhouse.md) |

[Loom이 맞지 않는 경우](https://github.com/ClickHouse/loom/blob/main/docs/getting-started/overview.md#when-it-does-not-fit)에서는 다른 도구가 더 적합한 요구 사항을 정리합니다.
