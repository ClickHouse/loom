# 환경 변수 레퍼런스

Loom의 거의 모든 구성은 설정 필드로 이루어집니다. 이는 `server.settings.Settings`의 필드에 대응하는 환경 변수 `LOOM_<FIELD>`이며, 기본값과 의미는 생성된 [구성 레퍼런스](https://github.com/ClickHouse/loom/blob/main/docs/reference/configuration.md)에 나와 있습니다. 이 페이지에서는 나머지를 다룹니다. 서버, CLI, SDK, 플러그인, 컨테이너 이미지, compose 파일, 운영자 스크립트가 `os.environ`(또는 셸의 `${VAR}`)으로 직접 읽는 변수입니다. 이 중 `LOOM_*` 변수는 `NON_SETTINGS_ENV`(`server/settings/_env.py`)에 나열되어 있으며, 웹훅 서명 시크릿 같은 변수군은 `NON_SETTINGS_ENV_PREFIXES`에 나열되어 있습니다. 서버의 알 수 없는 변수 경고는 이들을 건너뜁니다. `tests/unit/test_environment_reference.py`는 이 목록들과 이 페이지가 서로 일치하도록 유지합니다.

## 컨테이너 이미지와 uvicorn

이미지의 명령인 `scripts/serve.sh`가 이 값들을 읽어 uvicorn을 시작합니다. 이 스크립트는 값을 환경 변수에서만 가져오며 `.env`나 `LOOM_ENV_FILE`에서는 가져오지 않습니다(compose의 `env_file:`은 값을 환경에 설정합니다). 단, 설정 필드인 `LOOM_WEB_WORKERS`, `LOOM_TRUSTED_PROXIES`, `LOOM_RUNTIME_DIR`은 예외이며, 서버가 로드할 때 환경, env 파일, [설정 파일](https://github.com/ClickHouse/loom/blob/main/docs/reference/configuration.md) 순으로 해석합니다. uvicorn 자체의 `UVICORN_<OPTION>` 변수는 읽지 않습니다. `scripts/serve.sh`가 전달하지 않는 uvicorn 옵션에 대해 이 변수가 설정되어 있으면 웹 티어는 시작을 거부합니다.

| 변수                       | 기본값               | 의미                                                                                                                                                                                                                                                                                                                                                   |
| -------------------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `PORT`                     | `7777`               | uvicorn이 컨테이너 안에서 바인딩하는 포트입니다.                                                                                                                                                                                                                                                                                                       |
| `LOOM_LISTEN_HOST`         | `127.0.0.1`          | `uvicorn --host`: 수신 대기하는 주소입니다. 이미지는 `0.0.0.0`으로 설정합니다. `LOOM_BIND_HOST`는 시작 점검이 읽는 주소로 유지되며, 환경에 설정되어 있지 않으면 `scripts/serve.sh`가 루프백이 아닌 수신 주소로 설정합니다(env 파일이나 설정 파일의 값을 덮어씁니다).                                                                                  |
| `LOOM_WEB_WORKERS`         | CPU당 1개, 최대 8개  | `uvicorn --workers`. 설정하지 않으면 컨테이너가 사용할 수 있는 CPU(cpuset을 CPU 할당량으로 낮춘 값)당 1개이며, 메모리 1GiB당 최대 1개, 전체 최대 8개입니다. `.env`에 개수를 지정하지 않으면 compose 파일이 값을 설정합니다. `deploy/standalone`과 개발 스택은 2, 클라우드와 colour 스택은 1입니다. 설정 필드이기도 하며, 속도 제한기가 예산을 이 값으로 나눕니다。 |
| `LOOM_UVICORN_LOOP`        | `asyncio`            | `uvicorn --loop`: `asyncio`, `auto`, `uvloop` 중 하나입니다. uvloop는 git을 실행할 때마다 프로세스 전체를 포크하므로 루프가 멈춥니다.                                                                                                                                                                                                                   |
| `LOOM_TRUSTED_PROXIES`     | `127.0.0.1`          | `uvicorn --forwarded-allow-ips`: `X-Forwarded-For`/`-Proto`를 적용할 피어입니다.                                                                                                                                                                                                                                                                       |
| `LOOM_GRACEFUL_SHUTDOWN_S` | `10`                 | `uvicorn --timeout-graceful-shutdown`: 종료 중인 프로세스가 요청을 처리하며 비우는 시간입니다.                                                                                                                                                                                                                                                         |
| `LOOM_KEEP_ALIVE_S`        | `5`                  | `uvicorn --timeout-keep-alive`: 유휴 연결을 열어 두는 시간입니다. 연결을 재사용하는 로드 밸런서 뒤에서는 로드 밸런서의 유휴 타임아웃보다 길어야 합니다.                                                                                                                                                                                                 |

빌드 인수: `LOOM_BUILD_COMMIT`(이미지에 `LOOM_BUILD_COMMIT`으로 내장되며 `build_commit`으로 보고됩니다). 이미지에는 항상 로컬 CPU 임베더와 기본 모델이 포함되어 있으며 `LOOM_LOCAL_EMBEDDING_MODEL_DIR=/app/models`로 설정됩니다. 나머지 `ARG`는 컴파일러 티어 인덱서의 도구 체인 버전과 체크섬을 고정합니다(`GO_VERSION`, `NODE_VERSION`, `SCIP_GO_VERSION`, `SCIP_CLANG_VERSION`, 이들의 `*_SHA256*` 값, LLVM 서명 키의 지문인 `LLVM_SIGNER_FPR`). `scripts/install-code-toolchains.sh`는 npm으로 설치하는 도구(scip-typescript, scip-python, 패키지 관리자)의 버전을 고정합니다.

(먼저 ClickHouse를 고정하세요:
[설치 프로그램으로 설치한 환경 다운그레이드](https://github.com/ClickHouse/loom/blob/main/docs/operations/upgrades.md#downgrading-an-installer-install)).

compose 파일의 다른 `${LOOM_*}` 참조는 compose 수준의 기본값이 주어진 설정 필드와 위의
uvicorn 변수입니다. 설치 프로그램은 두 이미지 저장소(`LOOM_IMAGE_REPOSITORY`,
`LOOM_EXTRACTOR_IMAGE_REPOSITORY`), 태그, 포트, 바인드 호스트, `LOOM_CLICKHOUSE_IMAGE`가
주어지면 `.env`에 유지합니다. 기본 `.env`가 설정하는 내용은 [빠른 시작](../getting-started/quickstart.md)에서
설명합니다.
