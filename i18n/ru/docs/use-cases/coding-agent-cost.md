# Меньшая стоимость модели для кодинг-агентов

С плагином Loom и индексом кода Claude Code отвечал на вопросы о кодовой базе ClickHouse
со стоимостью модели на 6–21% ниже, чем без него, на всех трёх измеренных наборах вопросов. Экономия составила 20% на 24 вопросах с оценкой ответов (качество ответов 0.84 против
0.78), 21% на 36 концептуальных вопросах и 6% на 24 многошаговых вопросах, где отслеживание бага
до его исправления в релизной ветке стоило одинаково в обоих случаях.

<a id="what-was-measured"></a>

## Что измерялось

В обоих вариантах запускался Claude Code (`claude-sonnet-5`) на одной и той же копии репозитория: одна обычная сессия, другая
с плагином Loom и набором инструментов `coding`. Стоимость — это весь счёт за модель за сессию;
вызовы моделей на стороне сервера Loom, хостинг и индексация в неё не входят. Сравнение оценивает
плагин целиком; индекс кода и память оно не разделяет. Результаты
относятся только к проверенным нагрузкам. С Loom вопрос занимает больше времени по часам:
поиск плагина на каждый запрос и обращения MCP добавляют задержку. Как стоимость одного вопроса сравнивается с разбросом между запусками, описано на странице результатов.
[С Loom и без Loom](https://github.com/ClickHouse/loom/blob/main/docs/benchmarks/results.md#with-and-without-loom) содержит все наборы, протокол
и артефакты, а [оценка Loom](https://github.com/ClickHouse/loom/blob/main/docs/getting-started/evaluate.md) показывает, как
измерить его на вашем собственном репозитории.

О памяти, которую читает модель вместо всей истории чата, см.
[память агента](agent-memory.md#measured).

<a id="how-the-plugin-is-designed-to-save"></a>

## Как плагин рассчитан на экономию

- **Ответы из индекса вместо чтения файлов.** `code.symbol`, `code.callers` и `code.search`
  возвращают строки, отвечающие на вопрос о структуре. [Индекс кода](code-intelligence.md)
- **Сохранённый контекст вместо повторного поиска.** Решения и выводы, сохранённые в сессии, загружаются в начале следующей сессии. [Общая память](agent-memory.md)

Loom также записывает, сколько он тратит на эмбеддинги и вызовы LLM, по каждой операции.
[Стоимость и использование](https://github.com/ClickHouse/loom/blob/main/docs/features/observability/cost-and-usage.md)
