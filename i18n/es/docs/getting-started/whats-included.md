# Qué incluye

Esta página enumera las principales capacidades de Loom, autoalojadas desde el repositorio con licencia Apache-2.0: una sección por área, con cada fila enlazada a la página que la describe. El [índice de la documentación](https://github.com/ClickHouse/loom/blob/main/docs/index.md) muestra el resto de la documentación. Varias capacidades deben activarse; la página enlazada explica cómo, y los interruptores booleanos que se cargan como false se enumeran en [estado](https://github.com/ClickHouse/loom/blob/main/docs/reference/status.md). El embedder lo eliges tú: el modelo local incluido, un proveedor alojado o un endpoint compatible con OpenAI que ejecutes tú mismo. La extracción, los resúmenes y las respuestas con citas necesitan un LLM real ([modelos y claves de API](https://github.com/ClickHouse/loom/blob/main/docs/getting-started/models-and-keys.md)).
