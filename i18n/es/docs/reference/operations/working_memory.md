<!-- Generated by `python scripts/codegen/docs_reference.py` from the op registry; edit the models, not this page. -->

Los campos de identidad (`org`, `namespace`, `agent`, `user_id`, `session_id`) se rellenan a partir del token y de la sesión MCP cuando el transporte puede hacerlo; en una llamada HTTP sin token a un servidor de un solo usuario, se rellena la org de la instalación en todas las ops excepto `code.*` y `tracker.*` (que conservan la de su plano), y en [algunas ops](https://github.com/ClickHouse/loom/blob/main/docs/reference/http-api.md#request) también su espacio de nombres y su agente; consulta [identidades y espacios de nombres](https://github.com/ClickHouse/loom/blob/main/docs/concepts/identities-and-namespaces.md). ## `working_memory.append`

Agrega texto a un bloque de memoria de trabajo y lo crea si no existe.

`POST /v1/working_memory.append` · MCP `loom_working_memory_append` · rol `writer` · escritura

| Campo de entrada | Tipo | Valor por defecto | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obligatorio | El tenant (primer elemento de la tupla de identidad). |
| `namespace` | `str` | obligatorio | El espacio de nombres que la operación lee o escribe. |
| `agent` | `str` | obligatorio | El agente que escribe o lee; `'-'` o `'*'` significa cualquier agente cuando la operación lo permite. |
| `user_id` | `str` | `'-'` | El usuario final al que pertenece la fila; `'-'` si no hay ninguno. |
| `session_id` | `str` | `'-'` | La sesión o conversación a la que pertenece la fila; `'-'` si no hay ninguna. |
| `run_id` | `str` | `'-'` | La ejecución del agente (ámbito de tarea) a la que pertenece la llamada; `'-'` si no hay ninguna. |
| `block_key` | `str` | `'scratchpad'` | El bloque al que se agrega; un bloque inexistente se crea con el límite de tamaño por defecto. |
| `addition` | `str` | obligatorio | Texto que se agrega al final del bloque. |
| `separator` | `str` | `'\n'` | Se coloca entre el texto existente y `addition`; no se usa cuando el bloque es nuevo. |

| Campo de salida | Tipo | Significado |
| --- | --- | --- |
| `block_key` | `str` | El bloque que se escribió. |
| `version` | `int` | Versión de la fila que creó esta escritura (una marca de tiempo en nanosegundos). |
| `char_limit` | `int` | El límite de tamaño del bloque en caracteres después de la escritura. |
| `value_length` | `int` | Longitud del contenido del bloque después de la escritura, en caracteres. |

Renderiza bloques de memoria de trabajo como XML o markdown. context.pack ya incluye esta sección; el renderizado directo se usa sobre todo en código de SDK o de orquestación personalizada.

`POST /v1/working_memory.render` · MCP `loom_working_memory_render` · rol `viewer` · lectura

| Campo de entrada | Tipo | Valor por defecto | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obligatorio | El tenant (primer elemento de la tupla de identidad). |
| `namespace` | `str` | obligatorio | El espacio de nombres que la operación lee o escribe. |
| `agent` | `str` | obligatorio | El agente que escribe o lee; `'-'` o `'*'` significa cualquier agente donde la operación lo permita. |
| `user_id` | `str` | `'-'` | El usuario final al que pertenece la fila; `'-'` para ninguno. |
| `session_id` | `str` | `'-'` | La sesión o conversación a la que pertenece la fila; `'-'` para ninguna. |
| `run_id` | `str` | `'-'` | La ejecución del agente (ámbito de tarea) a la que pertenece la llamada; `'-'` para ninguna. |
| `block_keys` | `list[str]` | *(calculado)* | Solo estos bloques (como máximo 20); vacío = todos los bloques vigentes en el ámbito. |

| Campo de salida | Tipo | Significado |
