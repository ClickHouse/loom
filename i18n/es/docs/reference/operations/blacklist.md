# Operaciones de `blacklist`

Los campos exactos que recibe y devuelve cada operación `blacklist.*`.

<!-- Generated by `python scripts/codegen/docs_reference.py` from the op registry; edit the models, not this page. -->

Cada op es `POST /v1/<op>` sobre HTTP y la herramienta MCP `loom_<op>`. Los campos de identidad (`org`, `namespace`, `agent`, `user_id`, `session_id`) se rellenan a partir del token y de la sesión MCP cuando el transporte puede hacerlo; en una llamada HTTP sin token en un servidor de un solo usuario, se rellena la org de la instalación en todas las ops salvo `code.*` y `tracker.*` (que conservan la de su plano), y en [algunas ops](https://github.com/ClickHouse/loom/blob/main/docs/reference/http-api.md#request) también su espacio de nombres y su agente; consulta [identidades y espacios de nombres](https://github.com/ClickHouse/loom/blob/main/docs/concepts/identities-and-namespaces.md). Los campos de entrada desconocidos se atienden y se nombran en `ignored_args`.

## `blacklist.add`

Rechaza las escrituras futuras de memoria cuyo valor coincida con un patrón.

`POST /v1/blacklist.add` · MCP `loom_blacklist_add` · rol `writer` · idempotente · auditada

| Campo de entrada | Tipo | Valor por defecto | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obligatorio | El tenant (primer elemento de la tupla de identidad). |
| `namespace` | `str` | obligatorio | El espacio de nombres que la op lee o escribe. |
| `pattern` | `str` | obligatorio | El texto que se rechaza, comparado con distinción de mayúsculas y minúsculas con un valor almacenado: como subcadena, o como regex de como máximo 256 caracteres. |
| `pattern_type` | `Literal['substring', 'regex']` | `'substring'` | `substring` (texto plano) o `regex` (RE2, en las escrituras y en el barrido; acotada al añadir). |
| `scope` | `Literal['namespace', 'org', 'global']` | `'namespace'` | Alcance: `namespace` (solo este), `org` (todos los espacios de nombres; requiere admin de la org) o `global` (todos los tenants; requiere admin de la plataforma). |
| `reason` | `str` | `''` | Por qué existe el patrón; se almacena y se lista. |
| `created_by` | `str` | `''` | Autor registrado solo cuando la llamada no tiene un principal autenticado que estampar. |
| `sweep` | `bool` | `False` | Marca también con tombstone las filas vivas que el patrón ya coincide: dentro de esta org, y dentro del espacio de nombres si el patrón es de ese alcance. |

| Campo de salida | Tipo | Significado |
| --- | --- | --- |
| `pattern_id` | `str` | El id del nuevo patrón, para `blacklist.sweep` y `blacklist.remove`. |
| `created_at` | `datetime` | Cuándo se almacenó el patrón (UTC). |
| `swept` | `int` | Filas que el barrido marcó con tombstone; 0 sin `sweep`. |
| `swept_truncated` | `bool` | True cuando coincidieron más filas de las que toma un barrido; llama a `blacklist.sweep`. |
| `sweep_error` | `str` | "" cuando el barrido terminó; si no, el motivo (el patrón queda almacenado en ambos casos): `<code>: <message>` (vuelve a ejecutar con blacklist.sweep), el motivo de RE2 cuando una regex no puede ejecutarse (no se ejecutó ninguna consulta), o el tipo de error con el que falló la consulta de coincidencia. |

## `blacklist.list`

Lista los patrones que impiden almacenar memoria.

`POST /v1/blacklist.list` · MCP `loom_blacklist_list` · rol `viewer` · lectura · no aparece en el listado `all` de MCP

| Campo de entrada | Tipo | Valor por defecto | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obligatorio | El tenant (primer elemento de la tupla de identidad). |
| `namespace` | `str` | obligatorio | El espacio de nombres que la op lee o escribe. |
| `scope` | `Literal['namespace', 'org', 'global'] \| None` | `None` | scope=None devuelve todos los patrones que se aplican a esta (org, namespace), lo que incluye también los patrones de alcance superior (de toda la org, globales): el conjunto de reglas efectivo, no solo los fijados literalmente a este alcance. |
| `limit` | `int` | `100` | Como máximo esta cantidad de patrones, de 1 a 1000, los más recientes primero. |

| Campo de salida | Tipo | Significado |
| --- | --- | --- |
| `rows` | `list[_BlacklistRow]` | Los patrones vivos que coinciden con el filtro de alcance, los más recientes primero. |

<a id="blacklistremove"></a>

## `blacklist.remove`

Elimina un patrón de blacklist añadido previamente.

`POST /v1/blacklist.remove` · MCP `loom_blacklist_remove` · rol `admin` · idempotente · auditada · no aparece en el listado `all` de MCP

| Campo de entrada | Tipo | Valor por defecto | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obligatorio | El tenant (primer elemento de la tupla de identidad). |
| `pattern_id` | `str` | obligatorio | El patrón que se marca con tombstone; un patrón de espacio de nombres fuera del alcance del llamante responde `removed=false`. |
| `removed_by` | `str` | `''` | Se registra solo en el marcador de versión de la caché de blacklist, no en la fila del patrón. |
| `reason` | `str` | `''` | Se acepta pero no se almacena. |

| Campo de salida | Tipo | Significado |
| --- | --- | --- |
| `removed` | `bool` | False cuando ningún patrón vivo con ese id es visible para el llamante. |
| `removed_at` | `datetime \| None` | Cuándo se marcó el patrón con tombstone (UTC); null cuando no se eliminó nada. |

<a id="blacklistsweep"></a>

## `blacklist.sweep`

Marca con tombstone las filas vivas que coinciden con un patrón existente.

`POST /v1/blacklist.sweep` · MCP `loom_blacklist_sweep` · rol `writer` · idempotente · auditada · no aparece en el listado `all` de MCP

| Campo de entrada | Tipo | Valor por defecto | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obligatorio | El tenant (primer elemento de la tupla de identidad). |
| `namespace` | `str` | obligatorio | El espacio de nombres que la op lee o escribe. |
| `pattern_id` | `str` | obligatorio | El patrón vivo con el que se barre; un id desconocido o fuera del alcance del llamante responde 404. |

| Campo de salida | Tipo | Significado |
| --- | --- | --- |
| `pattern_id` | `str` | El patrón con el que se barrió, devuelto tal cual. |
| `matched` | `int` | Filas vivas que el patrón coincidió en esta llamada: como máximo 5,000 en ClickHouse, más, con la autoridad Postgres, las cabezas aparcadas que esta llamada marcó con tombstone. |
| `tombstoned` | `int` | Filas que esta llamada marcó con tombstone. |
| `truncated` | `bool` | True cuando coincidieron más filas de las que toma una llamada; vuelve a llamar. |
| `error` | `str` | "" cuando el barrido terminó; si no, `<code>: <message>` una vez que puede haber filas aplicadas (vuelve a llamar), el motivo de RE2 cuando una regex no puede ejecutarse (no se ejecutó ninguna consulta), o el tipo de error con el que falló la consulta de coincidencia; un fallo anterior a eso es el de la llamada. |
