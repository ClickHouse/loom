# Operaciones de `consolidations`

Los campos exactos que recibe y devuelve cada operación `consolidations.*`.

<!-- Generated by `python scripts/codegen/docs_reference.py` from the op registry; edit the models, not this page. -->

Cada op es `POST /v1/<op>` por HTTP y la herramienta MCP `loom_<op>`. Los campos de identidad (`org`, `namespace`, `agent`, `user_id`, `session_id`) se rellenan a partir del token y de la sesión MCP cuando el transporte puede hacerlo; en una llamada HTTP sin token en un servidor de un solo usuario, se rellena la org de la instalación en todas las ops excepto `code.*` y `tracker.*` (que conservan la de su plano), y en [algunas ops](https://github.com/ClickHouse/loom/blob/main/docs/reference/http-api.md#request) también su espacio de nombres y su agente; consulta [identidades y espacios de nombres](https://github.com/ClickHouse/loom/blob/main/docs/concepts/identities-and-namespaces.md). El [índice de operaciones](https://github.com/ClickHouse/loom/blob/main/docs/reference/operations.md) explica el rol, el tipo y el listado `all` de MCP. Los campos de entrada desconocidos se atienden y se nombran en `ignored_args`.

## `consolidations.list`

Historial de ejecuciones de consolidación con alcance de espacio de nombres. agent y user_id son opcionales: las ejecuciones se agregan entre ellos cuando se omiten.

`POST /v1/consolidations.list` · MCP `loom_consolidations_list` · rol `viewer` · lectura · no aparece en el toolset `all` de MCP

| Campo de entrada | Tipo | Valor por defecto | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obligatorio | El tenant (primer elemento de la tupla de identidad). |
| `namespace` | `str` | obligatorio | El espacio de nombres que la op lee o escribe. |
| `agent` | `str` | `'-'` | El agente que escribe o lee; `'-'` o `'*'` significa cualquier agente donde la op lo permita. |
| `user_id` | `str` | `'-'` | El usuario final al que pertenece la fila; `'-'` si ninguno. |
| `session_id` | `str` | `'-'` | La sesión o conversación a la que pertenece la fila; `'-'` si ninguna. |
| `run_id` | `str` | `'-'` | La ejecución del agente (ámbito de tarea) a la que pertenece la llamada; `'-'` si ninguna. |
| `limit` | `int` | `50` | Se devuelve como máximo este número de ejecuciones, las más recientes primero. |

| Campo de salida | Tipo | Significado |
| --- | --- | --- |
| `rows` | `list[ConsolidationRunRow]` | Las ejecuciones de consolidación del espacio de nombres, las más recientes primero, una por clúster examinado. |
