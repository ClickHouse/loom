# Operaciones de `insights`

Los campos exactos que recibe y devuelve cada operación `insights.*`.

Los campos de identidad (`org`, `namespace`, `agent`, `user_id`, `session_id`) se rellenan a partir del token y de la sesión MCP cuando el transporte puede hacerlo; en una llamada HTTP sin token en un servidor de un solo usuario, se rellena con la org de la instalación en todas las ops salvo `code.*` y `tracker.*` (que conservan la de su plano), y en [algunas ops](https://github.com/ClickHouse/loom/blob/main/docs/reference/http-api.md#request) también su espacio de nombres y su agente; consulta [identidades y espacios de nombres](https://github.com/ClickHouse/loom/blob/main/docs/concepts/identities-and-namespaces.md). Los campos de entrada desconocidos se atienden y se nombran en `ignored_args`.

## `insights.query`

Ejecuta una sola sentencia SQL SELECT (o WITH) de solo lectura sobre las tablas que lista `insights.catalog`, para las preguntas que ninguna otra lectura responde: recuentos, clasificaciones y tendencias sobre memorias, conflictos, uso, documentos y el…

`POST /v1/insights.query` · MCP `loom_insights_query` · rol `viewer` · lectura · no aparece en el conjunto de herramientas `all` de MCP

| Campo de entrada | Tipo | Valor por defecto | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obligatorio | El tenant (primer elemento de la tupla de identidad). |
| `namespace` | `str` | obligatorio | El espacio de nombres que la op lee o escribe. |
| `sql` | `str` | obligatorio | Una sentencia SELECT o WITH sobre las tablas que lista insights.catalog; solo lee las filas de este espacio de nombres. |
| `limit` | `int` | `100` | Máximo de filas que se devuelven (por defecto 100); si el límite del despliegue (LOOM_CH_ANALYSIS_MAX_RESULT_ROWS) es menor, prevalece este. |

| Campo de salida | Tipo | Significado |
| --- | --- | --- |
| `columns` | `list[AnalysisColumn]` | Las columnas de resultado de la sentencia, cada una con su tipo de ClickHouse. |
| `rows` | `list[list[Any]]` | Una lista por fila, en el orden de `columns`; las fechas, los UUID y los decimales como cadenas. |
| `row_count` | `int` | Cuántas filas contiene `rows`, como máximo `limit`. |
| `truncated` | `bool` | Coincidieron más filas que `limit`; acota la sentencia o agrega. |
| `sql_digest` | `str` | El digest que el registro de solicitudes guarda para `sql` (`sha256:<hex>/<length>`), contra el que se comprueba la cita de la sentencia. |
