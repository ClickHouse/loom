## `memory_schema.approve`

Aprueba (activa) o rechaza un esquema de registros propuesto.

`POST /v1/memory_schema.approve` · MCP `loom_memory_schema_approve` · rol `admin` · escritura · auditada · no aparece en el toolset `all` de MCP

| Campo de entrada | Tipo | Valor por defecto | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obligatorio | El tenant (primer elemento de la tupla de identidad). |
| `namespace` | `str` | obligatorio | El espacio de nombres que la op lee o escribe. |
| `name` | `str` | obligatorio | El esquema sobre el que se decide, por nombre. |
| `decision` | `Literal['approve', 'reject']` | obligatorio | `approve` pone el esquema en `active`; `reject` lo marca como `rejected`. |
| `reviewed_by` | `str` | `''` | Revisor de respaldo; se guarda solo cuando la solicitud no tiene un principal que registrar. |

| Campo de salida | Tipo | Significado |
| --- | --- | --- |
| `name` | `str` | El nombre del esquema, devuelto tal cual. |
| `status` | `str` | El estado almacenado ahora (`active` o `rejected`); vacío cuando ningún esquema tiene ese nombre. |
| `updated` | `bool` | False cuando ningún esquema tiene ese nombre y no se escribió nada. |

<a id="memory_schemalist"></a>

## `memory_schema.list`

Lista los esquemas de registros de un espacio de nombres; solo los activos, salvo que se use `include_proposed`.

`POST /v1/memory_schema.list` · MCP `loom_memory_schema_list` · rol `viewer` · lectura · no aparece en el toolset `all` de MCP

| Campo de entrada | Tipo | Valor por defecto | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obligatorio | El tenant (primer elemento de la tupla de identidad). |
| `namespace` | `str` | obligatorio | El espacio de nombres que la op lee o escribe. |
| `include_proposed` | `bool` | `False` | False lista solo los esquemas `active`; True lista todos los estados que no estén marcados como eliminados. |
| `limit` | `int` | `100` | Como máximo esta cantidad de esquemas (1–500), ordenados por nombre. |

| Campo de salida | Tipo | Significado |
| --- | --- | --- |
| `schemas` | `list[MemorySchemaSummary]` | Los esquemas del espacio de nombres con sus campos, ordenados por nombre. |

## `memory_schema.propose`

Registra un esquema de registros como `proposed`, para que un administrador lo apruebe o lo rechace.

`POST /v1/memory_schema.propose` · MCP `loom_memory_schema_propose` · rol `writer` · escritura · auditada · no aparece en el toolset `all` de MCP

| Campo de entrada | Tipo | Valor por defecto | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obligatorio | El tenant (primer elemento de la tupla de identidad). |
| `namespace` | `str` | obligatorio | El espacio de nombres que la op lee o escribe. |
| `name` | `str` | obligatorio | El nombre del esquema; memory.record.write y las consultas lo referencian por este nombre. |
| `description` | `str` | `''` | Texto libre que se guarda con el esquema y que devuelve memory_schema.list. |
| `fields` | `list[SchemaFieldInput]` | obligatorio | Los contratos de los campos (1–64); un tipo, una restricción o un patrón incorrectos se rechazan al registrar. |
| `created_by` | `str` | `''` | Autor de respaldo; se guarda solo cuando la solicitud no tiene un principal que registrar. |
| `status` | `Literal['active', 'proposed']` | `'active'` | `active` se puede escribir de inmediato; `proposed` espera a memory_schema.approve. |

| Campo de salida | Tipo | Significado |
| --- | --- | --- |
| `schema_id` | `str` | El id del nuevo esquema; cada llamada de registro genera uno nuevo. |
| `name` | `str` | El nombre del esquema, devuelto tal cual. |
| `field_count` | `int` | Cuántos campos declara el esquema. |
| `status` | `str` | El estado con el que se guardó: `active` o `proposed`. |
