## `extraction_policy.clear`

Elimina la política del ámbito.

`POST /v1/extraction_policy.clear` · MCP `loom_extraction_policy_clear` · rol `org_admin` · idempotente · auditada · no aparece en el conjunto de herramientas `all` de MCP

| Campo de entrada | Tipo | Valor por defecto | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obligatorio | El tenant (primer elemento de la tupla de identidad). |
| `scope` | `Literal['org', 'namespace']` | obligatorio | `org` elimina la política propia de la org; `namespace` elimina la de ese espacio de nombres y deja vigente la de la org. |
| `namespace` | `str` | `''` | El espacio de nombres cuya política se elimina; se ignora con el ámbito `org`. |

| Campo de salida | Tipo | Significado |
| --- | --- | --- |
| `org` | `str` | El tenant (primer elemento de la tupla de identidad). |
| `scope` | `Literal['org', 'namespace']` | `org` o `namespace`, según lo solicitado. |
| `namespace` | `str` | El espacio de nombres para el ámbito `namespace`; "" para el ámbito `org`. |
| `policy` | `str` | La política de este ámbito; "" cuando no hay ninguna. |
| `updated_by` | `str` | Quién la estableció; "" cuando no hay ninguna. |
| `updated_at` | `datetime \| None` | Cuándo se estableció (UTC); None cuando no hay ninguna. |
| `effective` | `str` | Bajo qué política se ejecutan las extracciones en este ámbito: la de la org y luego la del espacio de nombres; "" cuando no hay ninguna. |
| `namespace_policies` | `list[NamespacePolicy]` | Para el ámbito `org`: cada espacio de nombres de la org que tiene una política propia, por nombre, incluido el de un espacio de nombres eliminado, que sigue contando para LOOM_EXTRACTION_POLICY_MAX_NAMESPACES hasta que se borra. |
