# Operações de `profile_schema`

Os campos exatos que cada operação `profile_schema.*` recebe e retorna.

<!-- Generated by `python scripts/codegen/docs_reference.py` from the op registry; edit the models, not this page. -->

Os campos de identidade (`org`, `namespace`, `agent`, `user_id`, `session_id`) são preenchidos a partir do token e da sessão MCP quando o transporte consegue; em uma chamada HTTP sem token em um servidor de usuário único, é preenchida a org da instalação em todas as ops, exceto `code.*` e `tracker.*` (que mantêm a do seu plano), e em [algumas ops](https://github.com/ClickHouse/loom/blob/main/docs/reference/http-api.md#request) também o namespace e o agente; veja [identidades e namespaces](../../concepts/identities-and-namespaces.md). ## `profile_schema.clear`

Limpa o schema: nenhum perfil é criado ou recriado para o namespace, e as leituras respondem `no_schema`.

`POST /v1/profile_schema.clear` · MCP `loom_profile_schema_clear` · papel `admin` · idempotente · auditada · não listada no toolset `all` do MCP

| Campo de entrada | Tipo | Padrão | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obrigatório | O tenant (primeiro elemento da tupla de identidade). |
| `namespace` | `str` | obrigatório | O namespace que a op lê ou grava. |

| Campo de saída | Tipo | Significado |
| --- | --- | --- |
| `found` | `bool` | False quando o namespace não tem schema de perfil. |
| `json_schema` | `dict[str, Any]` | O schema como o admin o definiu, na ordem de chaves dele; {} quando não encontrado. |
| `schema_sha256` | `str` | SHA-256 das propriedades do schema (não dos títulos nem da ordem), que cada perfil nomeia. |
| `updated_by` | `str` | O ator (`human:<subject>` ou `process:<subject>`) que o definiu ou limpou por último; vazio quando não encontrado, ou para um token restrito a um usuário. |
| `updated_at` | `datetime \| None` | Quando foi definido ou limpo por último; None quando não encontrado. |

## `profile_schema.set`

Define o schema de perfil do namespace.

`POST /v1/profile_schema.set` · MCP `loom_profile_schema_set` · papel `admin` · idempotente · auditada · não listada no toolset `all` do MCP

| Campo de entrada | Tipo | Padrão | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obrigatório | O tenant (primeiro elemento da tupla de identidade). |
| `namespace` | `str` | obrigatório | O namespace que a op lê ou grava. |
