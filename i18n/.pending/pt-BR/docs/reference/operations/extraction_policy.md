## `extraction_policy.clear`

Remove a política do escopo.

`POST /v1/extraction_policy.clear` · MCP `loom_extraction_policy_clear` · role `org_admin` · idempotente · auditada · não listada no toolset `all` do MCP

| Campo de entrada | Tipo | Padrão | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obrigatório | O tenant (primeiro elemento da tupla de identidade). |
| `scope` | `Literal['org', 'namespace']` | obrigatório | `org` remove a política da própria org; `namespace` remove a desse namespace, mantendo a da org em vigor. |
| `namespace` | `str` | `''` | O namespace cuja política será removida; ignorado para o escopo `org`. |

| Campo de saída | Tipo | Significado |
| --- | --- | --- |
| `org` | `str` | O tenant (primeiro elemento da tupla de identidade). |
| `scope` | `Literal['org', 'namespace']` | `org` ou `namespace`, conforme solicitado. |
| `namespace` | `str` | O namespace para o escopo `namespace`; "" para o escopo `org`. |
| `policy` | `str` | A política deste escopo; "" quando não há nenhuma definida. |
| `updated_by` | `str` | Quem a definiu; "" quando não há nenhuma definida. |
| `updated_at` | `datetime \| None` | Quando foi definida (UTC); None quando não há nenhuma definida. |
| `effective` | `str` | Sob qual política as extrações neste escopo são executadas: a da org, depois a do namespace; "" quando nenhuma das duas está definida. |
| `namespace_policies` | `list[NamespacePolicy]` | Para o escopo `org`: todo namespace da org que possui uma política própria, por nome, incluindo a de um namespace excluído, que continua contando para LOOM_EXTRACTION_POLICY_MAX_NAMESPACES até ser removida. |

## `extraction_policy.set`

Define a política do escopo, substituindo a que ele tinha.

`POST /v1/extraction_policy.set` · MCP `loom_extraction_policy_set` · role `org_admin` · idempotente · auditada · não listada no toolset `all` do MCP

| Campo de entrada | Tipo | Padrão | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obrigatório | O tenant (primeiro elemento da tupla de identidade). |
| `scope` | `Literal['org', 'namespace']` | obrigatório | `org` define a política da própria org, que todo namespace segue (`namespace` é ignorado); `namespace` define as regras que esse namespace acrescenta a ela. |
| `namespace` | `str` | `''` | O namespace ao qual uma política de escopo `namespace` se destina; ignorado para o escopo `org`. |
| `policy` | `str` | obrigatório | As regras em linguagem simples, no máximo 4,096 caracteres; substitui a política do escopo. |

| Campo de saída | Tipo | Significado |
| --- | --- | --- |
| `org` | `str` | O tenant (primeiro elemento da tupla de identidade). |
| `scope` | `Literal['org', 'namespace']` | `org` ou `namespace`, conforme solicitado. |
| `namespace` | `str` | O namespace para o escopo `namespace`; "" para o escopo `org`. |
| `policy` | `str` | A política deste escopo; "" quando não há nenhuma definida. |
| `updated_by` | `str` | Quem a definiu; "" quando não há nenhuma definida. |
| `updated_at` | `datetime \| None` | Quando foi definida (UTC); None quando não há nenhuma definida. |
| `effective` | `str` | Sob qual política as extrações neste escopo são executadas: a da org, depois a do namespace; "" quando nenhuma das duas está definida. |
| `namespace_policies` | `list[NamespacePolicy]` | Para o escopo `org`: todo namespace da org que possui uma política própria, por nome, incluindo a de um namespace excluído, que continua contando para LOOM_EXTRACTION_POLICY_MAX_NAMESPACES até ser removida. |
