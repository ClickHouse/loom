# Operações de `memory_schema`

Os campos exatos que cada operação `memory_schema.*` recebe e retorna.

Os campos de identidade (`org`, `namespace`, `agent`, `user_id`, `session_id`) são preenchidos a partir do token e da sessão MCP quando o transporte consegue; em uma chamada HTTP sem token em um servidor de usuário único, é preenchida a org da instalação em todas as ops, exceto `code.*` e `tracker.*` (que mantêm a do seu plano), e em [algumas ops](https://github.com/ClickHouse/loom/blob/main/docs/reference/http-api.md#request) também o namespace e o agente; veja [identidades e namespaces](../../concepts/identities-and-namespaces.md). <a id="memory_schemaapprove"></a>

## `memory_schema.approve`

Aprova (torna ativo) ou rejeita um schema de registro proposto.

`POST /v1/memory_schema.approve` · MCP `loom_memory_schema_approve` · papel `admin` · escrita · auditada · não listada no toolset `all` do MCP

| Campo de entrada | Tipo | Padrão | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obrigatório | O tenant (primeiro elemento da tupla de identidade). |
| `namespace` | `str` | obrigatório | O namespace que a op lê ou grava. |
| `name` | `str` | obrigatório | O schema sobre o qual decidir, pelo nome. |
| `decision` | `Literal['approve', 'reject']` | obrigatório | `approve` torna o schema `active`; `reject` o marca como `rejected`. |
| `reviewed_by` | `str` | `''` | Revisor de reserva, armazenado apenas quando a requisição não tem um principal para registrar. |

| Campo de saída | Tipo | Significado |
| --- | --- | --- |
| `name` | `str` | O nome do schema, devolvido como recebido. |
| `status` | `str` | O status agora armazenado (`active` ou `rejected`); vazio quando nenhum schema tem esse nome. |
| `updated` | `bool` | False quando nenhum schema tem o nome e nada foi gravado. |

<a id="memory_schemalist"></a>

## `memory_schema.list`

Lista os schemas de registro de um namespace, somente os ativos, a menos que `include_proposed` seja usado.

`POST /v1/memory_schema.list` · MCP `loom_memory_schema_list` · papel `viewer` · leitura · não listada no toolset `all` do MCP

| Campo de entrada | Tipo | Padrão | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obrigatório | O tenant (primeiro elemento da tupla de identidade). |
| `namespace` | `str` | obrigatório | O namespace que a op lê ou grava. |
| `include_proposed` | `bool` | `False` | False lista apenas schemas `active`; True lista todos os status que não sejam tombstone. |
| `limit` | `int` | `100` | No máximo este número de schemas (1–500), ordenados por nome. |

| Campo de saída | Tipo | Significado |
| --- | --- | --- |
| `schemas` | `list[MemorySchemaSummary]` | Os schemas do namespace com seus campos, ordenados por nome. |

<a id="memory_schemapropose"></a>

## `memory_schema.propose`

Registra um schema de registro como `proposed`, para um admin aprovar ou rejeitar.

`POST /v1/memory_schema.propose` · MCP `loom_memory_schema_propose` · papel `writer` · escrita · auditada · não listada no toolset `all` do MCP

| Campo de entrada | Tipo | Padrão | Significado |
| --- | --- | --- | --- |
| `org` | `str` | obrigatório | O tenant (primeiro elemento da tupla de identidade). |
| `namespace` | `str` | obrigatório | O namespace que a op lê ou grava. |
| `name` | `str` | obrigatório | O nome do schema; memory.record.write e as consultas o referenciam por esse nome. |
| `description` | `str` | `''` | Texto livre armazenado com o schema e retornado por memory_schema.list. |
| `fields` | `list[SchemaFieldInput]` | obrigatório | Os contratos dos campos (1–64); um tipo, restrição ou padrão inválido é rejeitado no registro. |
| `created_by` | `str` | `''` | Autor de reserva, armazenado apenas quando a requisição não tem um principal para registrar. |
| `status` | `Literal['active', 'proposed']` | `'active'` | `active` pode receber escrita imediatamente; `proposed` aguarda memory_schema.approve. |

| Campo de saída | Tipo | Significado |
| --- | --- | --- |
| `schema_id` | `str` | O id do novo schema; cada chamada de registro gera um novo. |
| `name` | `str` | O nome do schema, devolvido como recebido. |
| `field_count` | `int` | Quantos campos o schema declara. |
| `status` | `str` | O status com que foi armazenado: `active` ou `proposed`. |
